# Phase 4 Post-GA Evidence Bundle

Use this folder as the source of truth for Phase 4 execution artifacts.

## Structure
- `phase4-execution-log.md`: single log for daily ops, drills, weekly review, and exit decision
- `daily/`: optional daily raw snapshots (`ops-stats`, `ops-alerts`)
- `drills/`: rollback and drain drill evidence
- `weekly/`: weekly stability summaries

## Minimum artifacts to close Phase 4
- 14-day execution log with SLO values per day
- rollback drill evidence set
- drain-mode drill evidence set
- at least 2 weekly summaries
- final Phase 4 completion decision recorded in execution log
